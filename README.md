# MyOC - 快速预览和维护 Live2D 角色

MyOC 是一款为原创 Live2D 角色（OC，Original Character）设计的 **基于 Live2D 官方 SDK 的本地参数调试工具**。它无需依赖复杂的后端服务器或 VPN，支持全本地端渲染、参数随机、截图导出，并可与 AI 智能体联动进行全自动化模型调试。

---

## ✨ 核心特性

* 🎨 **本地 Live2D 渲染**：支持导入 `.model3.json` 规范文件，在本地画布流畅渲染模型。
* 🎲 **多维度参数随机与分类**：内置参数分类引擎，智能区分外观参数（头发、眼睛、服装颜色等）与物理/动作参数，支持按类自由随机、快速找灵感。
* 📋 **随机方案保存与恢复**：将满意的参数方案一键保存，随时还原、删除管理。
* 📸 **透明背景截图**：一键切换透明背景 / 9 种常用高纯度底色，方便做立绘。
* 🤖 **AI 智能体对接**：内置本地 API，支持与智能体联动完成参数调试、外观批量微调。

## 📥 下载安装

前往 [GitHub Releases](https://github.com/kinaito/myoc/releases) 下载对应平台的安装包。

### 🍎 macOS 安装指引

1. 下载 `Myoc.pkg` 并双击安装。
2. 安装完成后在「应用程序」中找到 `Myoc.app` 启动。
3. 首次运行若提示"无法验证开发者"：
   * **方法一**：按住 Control 键右键点击应用图标 → 选择「打开」→ 确认框里再次点「打开」；
   * **方法二**：前往「系统设置 → 隐私与安全」，在底部找到 `已阻止打开"Myoc"`，点「仍要打开」。

### 💻 Windows 安装指引

1. 下载并解压 `Myoc-Windows-vVer.zip`（Ver 为当前版本号）。
2. 双击解压文件夹内的 `Myoc.exe` 启动。
3. 首次运行若 Windows Defender SmartScreen 拦截：点「更多信息」→ 右下角选「仍要运行」。
